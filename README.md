### Featured project

[**codebase-qa-agent**](https://github.com/HurricaneTMXI/codebase-qa-agent): a LangGraph agent that answers questions about a real codebase and cites `file:line` for every claim. On 80 hand-checked questions it covered **93%** of the key facts, against **63%** for single-shot RAG. On impact questions ("what breaks if I change Z") the gap is 83% against 33%.
